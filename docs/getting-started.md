# Getting Started with FMToolkit

FMToolkit checks whether your code still does what it used to after a change - an AI rewrite, a refactor, or a migration - and reports the result as a GitHub Check directly on your pull requests.

**This page is under construction.** Full setup and usage documentation is coming soon.

In the meantime:

- Questions? Ask in [Discussions](https://github.com/URSA-Inc/fmtoolkit-support/discussions).
